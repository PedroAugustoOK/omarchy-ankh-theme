# Wallpapers

O Omarchy aceita imagens `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp` e `.webp`
diretamente nesta pasta. O Ankh mantém exatamente três wallpapers numerados,
todos em 3840×2160, para controlar a ordem no seletor de fundos.

- `01-ankh-study.png`
- `02-ankh-meadow.png`
- `03-ankh-window.png`
