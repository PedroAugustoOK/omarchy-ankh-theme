# Contribuindo

Obrigado por ajudar a manter o Ankh consistente e utilizável.

1. Mantenha a identidade: neutros frios, azul ardósia e acentos contidos.
2. Preserve exatamente três wallpapers 16:9 em `backgrounds/`; não substitua
   fotografias fornecidas por imagens geradas.
3. Use capturas reais para `preview.png` e `preview-unlock.png`.
4. Garanta contraste mínimo de 7:1 para texto principal e 4.5:1 para acentos
   e texto secundário.
5. Rode a validação descrita no README antes de abrir um pull request.
6. Evite arquivos que executem código: temas instalados pelo Git do Omarchy
   deliberadamente não aceitam `.lua`, configurações de terminal ou `vscode.json`.

Mudanças que afetem os dois modos devem ser levadas ao repositório Ankh Dark
quando houver um equivalente visual apropriado.
